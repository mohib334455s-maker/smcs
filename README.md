# SCMS — سیستم هوشمند مدیریت مارکیت تجارتی

سند جامع و تعاملی طراحی سیستم (Interactive System Blueprint) برای مدیریت مارکیت تجارتی.

این پروژه یک وب‌سایت تک‌صفحه‌ای مستندات است؛ نرم‌افزار عملیاتی متصل به دیتابیس واقعی نیست.

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده در ترمینال (معمولاً `http://localhost:5173`) را در مرورگر باز کنید.

## ساخت نسخه تولید

```bash
npm run build
npm run preview
```

## امکانات واقعی در این وب‌سایت

- ناوبری کناری RTL با پیمایش به بخش‌ها و نشانگر بخش فعال
- جست‌وجوی سراسری مستندات
- حالت روشن/تاریک
- داشبورد آماری با نمودارهای پویا (Recharts) و داده نمونه
- جدول‌های قابل جست‌وجو و مرتب‌سازی
- نمونه POS رستورانت (سبد، مالیات، تخفیف، جمع)
- نقشه دوبعدی SVG، ماتریس نقش‌ها، گردش کارها، فیلتر نیازمندی‌ها
- خروجی CSV واقعی از داده نمونه
- چاپ مستندات

## نمونه مفهومی / نیازمند Backend

- اتصال SMS / WhatsApp / ایمیل واقعی
- هوش مصنوعی متصل به مدل
- پایگاه داده عملیاتی PostgreSQL
- دروازه/دوربین پارکینگ و بایومتریک
- PWA آفلاین کامل

## پشته فنی

- React + TypeScript + Vite
- Tailwind CSS v4

- Recharts
